Receptsajt byggd med HTML och CSS under Lexicons frontendutbildning,
vecka 1 till 4. Inget JavaScript.

## Sidor
- Startsida med kategorier och receptkort
- Receptsida för pannkakor
- Dela recept, ett formulär med validering i HTML och CSS

## Fokus utifrån undervisningen
- Tokens för färg (oklch och light-dark), typsnitt och avstånd
- Grid för sidlayout och kort, flex för meny och taggar
- :has() för avbockade ingredienser och feltexter
- :user-invalid och :user-valid i formuläret

## Källor
- CSS reset: Josh W. Comeau och Andy Bell (länkar i style.css)
- Typsnitt: Open Sans och Josefin Sans, Google Fonts (SIL OFL)
- Bilder: Lexicons Figma-mockup, används inom utbildningen
- Övriga bilder: Foodiesfeed och Unsplash. Bildkällor,
